# Функция /cover - Музыкальное видео с вращающейся обложкой

## Описание
Команда `/cover` позволяет создавать музыкальные видео с круглой вращающейся обложкой из MP3 файла и изображения.

## Как использовать

1. **Отправьте команду:**
   ```
   /cover
   ```

2. **Отправьте MP3 файл:**
   - Бот попросит отправить аудио файл
   - Формат: MP3 (проверяется автоматически)
   - Бот определит длительность трека

3. **Отправьте изображение:**
   - Бот попросит отправить обложку
   - Формат: PNG (или любое изображение)
   - Рекомендуемый размер: 512x512

4. **Получите результат:**
   - Бот создаст видео MP4 с:
     - Круглой обложкой (прозрачные края)
     - Вращением 360° каждые 10 секунд
     - Вашим аудио
   - Видео будет отправлено в чат

## Технические детали

### Безопасность
- ✅ Проверка whitelist (как у команды `/v`)
- ✅ Только для разрешённых чатов (`WHITELISTED_CHAT_IDS`)
- ✅ Только для разрешённых пользователей (`WHITELISTED_IDS`)
- ✅ Логирование всех действий

### FFmpeg обработка
```bash
# Круглая маска
scale=512:512,format=rgba
geq='lum=p(X,Y):a=if(lt(hypot(W/2-X,H/2-Y),W/2),255,0)'

# Вращение: 360° каждые 10 секунд
rotate=angle=2*PI*t/10:fillcolor=none:ow=512:oh=512
```

### Файлы

1. **src/cover-util.ts** - Основная логика:
   - `getAudioDuration()` - определяет длительность через FFprobe
   - `createRotatingCover()` - создаёт видео через FFmpeg
   - `coverConversation()` - диалог с пользователем (Grammy Conversations)

2. **src/setup.ts** - Регистрация:
   - Добавлен `SessionFlavor` и `ConversationFlavor` в тип контекста
   - Подключён плагин `conversations`
   - Зарегистрирован `coverConversation`
   - Команда добавлена в `/setMyCommands`

3. **src/index.ts** - Обработчик команды:
   - Проверка whitelist
   - Логирование попыток доступа
   - Запуск conversation

### Зависимости
```json
{
  "@grammyjs/conversations": "^2.1.0"
}
```

## Примеры логов

**Успешное создание:**
```
info: Cover conversation started | userId=123456789 username=john chatId=-1001234567890
info: Audio processed in cover conversation | userId=123456789 audioPath=/tmp/audio_123456789_1234567890.mp3 duration=180
info: Cover video created successfully | userId=123456789 duration=180
```

**Ошибка формата:**
```
warn: Invalid audio format in cover conversation | userId=123456789 mimeType=video/mp4
```

**Блокировка whitelist:**
```
warn: Cover command from non-whitelisted user | userId=999 username=unknown chatId=-1001234567890
```

## Временные файлы
- `/tmp/audio_<userId>_<timestamp>.mp3` - скачанное аудио
- `/tmp/image_<userId>_<timestamp>.png` - скачанное изображение
- `/tmp/video_<userId>_<timestamp>.mp4` - итоговое видео

**Автоматическая очистка** после отправки или при ошибке.

## Ограничения
- Размер файла: по ограничениям Telegram API
- Длительность: без ограничений (определяется аудио)
- Параллельная работа: поддерживается (каждый пользователь = отдельный диалог)

## Тестирование
1. Создайте тестовый MP3 файл (любая длительность)
2. Подготовьте PNG изображение 512x512
3. Отправьте `/cover` в разрешённом чате
4. Проверьте создание видео
5. Убедитесь в автоматической очистке временных файлов
